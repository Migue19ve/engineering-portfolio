## Publication rule

New examples must be built from scratch with invented data. Every screenshot must be captured from the demo, with no private tabs, notifications, account details, client branding, or infrastructure addresses. Review every tracked file and Git history before publishing.

Nothing here authorizes automatic applications, recruiter messages, or follow-up emails. Those require a user request.
